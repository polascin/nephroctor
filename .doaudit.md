# Spustenie ďalšieho auditného behu — Nephroctor

Operačný postup. **Kontrolný zoznam, pravidlá a história behov sú v [`.audit.md`](.audit.md)** —
tento súbor hovorí len *ako beh vykonať*, nie *čo kontrolovať*.

## Zadanie

Vykonaj ďalší beh hĺbkového auditu statickej multijazyčnej stránky **nephroctor.com**
podľa kontrolného zoznamu v [`.audit.md`](.audit.md) (14 oblastí), implementuj bezpečné
opravy a zapíš výsledok ako nový „Beh #X“.

## Zásada dôkazu

> **Každý bod kontrolného zoznamu sa uzatvára nameranou hodnotou alebo výstupom príkazu,
> nie vetou „je to v poriadku“.**

Behy #4 a #6 vyhlásili „žiadne nové nálezy“, hoci v kóde bolo v tom čase neplatné CSS
pravidlo a dve zlyhania kontrastu. Verdikt bez merania je pre tento audit neplatný výsledok.
Ak sa niečo nedá zmerať dostupnými nástrojmi, zapíš to ako **neoverené**, nie ako v poriadku.

## Postup

### 1. Pred začiatkom

```bash
git status --short          # pracovný strom musí byť čistý
git log --oneline -5
```

Prečítaj si v `.audit.md` sekciu **„Register regresií“** — to sú konkrétne chyby, ktoré
už v tomto projekte raz vznikli. Skontroluj ich ako prvé.

### 2. Automatické kontroly

Spusti všetky skripty zo sekcie **„Overovacie skripty“** v `.audit.md`. Sú navrhnuté tak,
aby bežali bez inštalácie čohokoľvek (Python 3 + Node sú v prostredí).

```bash
python .audit/check_structure.py     # HTML, odkazy, ID, nadpisy, rel=noopener
python .audit/check_contrast.py      # WCAG pomery, obe témy
python .audit/check_i18n.py          # úplnosť 24 jazykov × všetky kľúče, hreflang
python .audit/check_assets.py        # CSS tokeny, JSON-LD, manifest, sitemap, 3rd party
python .audit/check_fonts.py         # pokrytie znakov subsetmi, nevyžiadané subsety
python .audit/check_format.py        # konvencia formátovania projektu
node   .audit/check_lang_logic.js    # poradie výberu jazyka na hlavnej stránke
node   .audit/check_legal_logic.js   # výber SK/EN verzie právneho dokumentu
```

Ak ktorýkoľvek skript skončí nenulovým kódom, oprav príčinu skôr, než pokračuješ.

### 3. Manuálne kontroly

```bash
python -m http.server 8791 --bind 127.0.0.1
```

- Šírky **320 px, 768 px, 1200 px** — bez vodorovného posúvania.
- Zväčšenie na **200 %** — nič sa nestráca ani neprekrýva.
- Prechod **výhradne klávesnicou** cez celú stránku — fokus je vždy viditeľný.
- Prepni **všetkých 24 jazykov**; over, že sa mení `<title>`, meta description aj `lang`.
- Over gréčtinu (`el`) a bulharčinu (`bg`) — testujú grécky a cyrilický subset písma.
- Prepni **tmavý/svetlý režim** a obnov stránku — voľba musí zostať.
- Otvor všetkých **6 dokumentov v `legal/`** a v každom prepni SK/EN.
- Konzola prehliadača — **žiadne chyby ani varovania**.
- Karta **Network** — nesmie sa objaviť **žiadna** požiadavka mimo vlastnej domény.

### 4. Formátovanie a nasadenie

```bash
trunk check --all --no-progress      # ak je dostupný
```

Formátovanie gatuje `check_format.py` z kroku 2. **Prettier sa nepoužíva** —
v Behu #8 zmerané, že by prepísal 2034 z 918 riadkov `index.html`, teda zamenil
štýl namiesto opravy formátovania. Podrobnosti v `.audit.md`, sekcia 14.

Ak beh pridal akýkoľvek súbor, over, že ho kopíruje
`.github/workflows/deploy.yml` — `mirror --reverse --delete` zmaže na serveri
všetko, čo nie je v `deploy/`. Rovnako over, že sa nenasadzuje nič mŕtve;
krok „Prepare deploy directory“ vypisuje veľkosť payloadu.

### 5. Zápis

Do `.audit.md` pridaj nový „Beh #X“ v tvare:

```markdown
## Beh #X – RRRR-MM-DD: krátky názov

### Rozsah
### Nálezy a opravy      (závažnosť, príčina, oprava, dotknuté súbory)
### Namerané hodnoty     (konkrétne čísla, nie verdikty)
### Neoverené / odložené (s odôvodnením a odporúčaným postupom)
### Nasadenie
```

Ak beh odhalí, že niektorý predchádzajúci záznam bol vecne nesprávny, **neprepisuj ho** —
pridaj korekciu do aktuálneho behu. Auditná stopa sa neupravuje spätne.

### 6. Ukončenie

```bash
git diff --stat
git add -A && git commit -m "Audit Beh #X: ..."
```

`git push` **iba** na výslovnú žiadosť používateľa.

## Kedy prestať

Cyklus končí, keď beh nenájde **žiadnu novú bezpečne opraviteľnú chybu** a zároveň:

- všetkých 8 automatických skriptov prejde,
- register regresií je čistý,
- otvorené položky sú buď opravené, alebo zapísané v registri výnimiek
  s odôvodnením a ďalším postupom.

## Bezpečnostné pravidlá

- Neopravuj automaticky nič, čoho dopad si neposúdil samostatne.
- Uprednostni obranné riešenia, minimalizuj riziko regresie.
- Nezverejňuj citlivé údaje, kľúče ani heslá.
- **Nedopĺňaj údaje, ktoré nepoznáš.** Adresa, číslo živnostenského registra, IČ DPH
  a registračné číslo SLK sú v právnych dokumentoch zámerne označené `[DOPLNIŤ]`.
  Vymyslená hodnota v právnom dokumente je horšia chyba než chýbajúca.
- Neznižuj bezpečnostné nastavenia kvôli pohodliu.
